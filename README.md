# HUMB investor data

Public data file behind the HUMB Investor Finder page's **Refresh list** button.

- `humb-data.json` holds three lists: investors, quant traders and firms, and quant communities.
- It is updated weekly (Mondays, IST) and on request.
- It contains only publicly available information. Outreach notes and statuses are kept privately and are never stored here.
